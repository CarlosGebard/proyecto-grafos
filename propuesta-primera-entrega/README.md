# Optimización de Cobertura Territorial mediante Grafos

Repositorio documental de la primera entrega del proyecto semestral de Grafos y Algoritmos.

## Estructura

- `entregables/`: PDF entregable. Contiene la [propuesta inicial](entregables/propuesta-inicial.pdf) como referencia.
- `informe/`: fuentes editables del informe, bibliografía y figuras que se construirán en la siguiente etapa.
- `anexos/`: material complementario que sea pertinente para la entrega.

La implementación, los datos geoespaciales y los resultados experimentales están en la sección de [simulación](../simulacion/) de este mismo repositorio.
